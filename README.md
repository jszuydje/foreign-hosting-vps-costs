## 虚拟主机、VPS、独立服务器，先分清再掏钱

搜“国外虚拟主机”的人，最后买到的东西经常完全不同，因为这几个词常被混着叫。区别说穿了就是资源独占程度。

| 类型 | 资源怎么分 | IP 情况 | 适合谁 |
| --- | --- | --- | --- |
| 虚拟主机（共享主机） | 一台物理服务器分隔成若干份出售，共享 CPU、内存 | 大多是共享 IP，独立 IP 要加钱 | 个人博客、企业展示站 |
| VPS | CPU、内存、存储完全隔开，互不影响 | 独立 IP | 想自主掌控环境、用途不止挂网站的用户 |
| 独立服务器 | 整台机器归你 | 独立 IP | 站群、SEO 多 IP、大流量业务 |

虚拟主机的用途基本只有一个：托管网站。价格便宜、有现成控制面板，但性能有限，流量大了会吃力。VPS 等于一台独立服务器，装什么环境自己定，除了建站还能做网盘、跑亚马逊外贸这类用途。海外主机不管选哪种，都不需要备案，买完就能挂站。

## 下单前先算三笔账：续费、付款、退款

价格之外，真正决定体验的是续费价、付款方式和退款条款这三件事。它们藏在结算页和条款里，测评文章往往只报个首年价就完事了。

### 续费价才是真实成本

首年促销、续费恢复原价，是主机行业的常规操作。拿 GoDaddy 经济版算：首年 17 元/月，官方页面标的原价是 85 元/月，写着“节省 80%”。第一年 204 元，第二年起恢复到 1020 元/年，直接涨 5 倍，三年下来约 2244 元——这还是按当前标注的价格估算。连页面上的“免费 SSL 证书”都明确标注只含 1 年，续费年的证书政策下单前要看清。

SiteGround 同样是首年便宜、续费会贵一些的路子，而且它的 30 天退款只适用首次购买的共享主机，域名和附加服务不在退款范围里。

比较两家主机时，把“首年 + 续费 × 2”的三年总价摆出来看，比只盯首年数字靠谱得多。

### 付款方式能直接筛掉一半选项

SiteGround 只收 Visa、万事达、运通这类国际信用卡，不支持支付宝；想用 PayPal 得在购买时联系在线客服说明情况。手里没有国际信用卡的话，这家基本可以跳过，不用纠结。

支持支付宝的有 bluehost 香港机房、HawkHost 和 GoDaddy。对没有外币卡的读者，这一条就能定生死。

### 退款条款和域名的小坑

- GoDaddy 承诺 30 天不满意退款，官方口径是“不用填表、不问理由”。
- SiteGround 云主机 14 天、共享主机 30 天，且只限首次购买。
- 主机商“免费送域名”通常绑定首年促销，和主机捆在一起，日后退款、迁移都麻烦。域名建议在专门的域名注册商那里单独买（比如 NameSilo 这类），后缀就注册 .com；.tk、.ml、.ga 这类免费后缀别碰。

## 关于国外虚拟主机的几个高频问题

**国外虚拟主机需要备案吗？**
不需要。海外主机购买后直接托管网站，这也是很多人选它的核心原因。国内访问速度主要看机房和线路，香港、美国机房配合 CN2 GIA 这类优化线路会快很多。

**虚拟主机跑 WordPress 行吗？**
行。市面上大多数虚拟主机是 Linux 系统，对 WordPress、Discuz! 这类 PHP 程序支持很好，SiteGround 本身就是 WordPress 官方推荐的主机商。只有跑 ASP.NET 才需要专门找 Windows 主机。

**共享 IP 会有影响吗？**
大多数虚拟主机是共享 IP，同服务器上其他站点和你共用一个。写个人博客无所谓；对 IP 有要求的，要么买独立 IP 的虚拟主机（价格贵一些），要么直接上 VPS。
